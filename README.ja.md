# Umbra AutoRetainer

[English](README.md)

Umbra のツールバーに、AutoRetainer のリテイナー／潜水艦の状態を出します。

表示例: `R2|5　M0|4`

- **R** = リテイナー（回収できる人数 | ベンチャー中の人数）
- **M** = 潜水艦（回収できる隻数 | 航海中の隻数）
- クリックで AutoRetainer の `/ays` を開きます
- 色と、数えるキャラ／リテイナーはウィジェット設定で変えられます

## 入れ方

先に [Umbra](https://github.com/una-xiv/umbra) と [AutoRetainer](https://github.com/PunishXIV/AutoRetainer) を入れてください。

1. ゲーム内で Umbra の設定を開く
2. **Custom Plugins（カスタムプラグイン）** を開く
3. リポジトリのオーナーに `Qmeko` を入れる
4. リポジトリ名に `Umbra.AutoRetainer` を入れる
5. **Install** を押す
6. Umbra を再読み込みする
7. ツールバーに **AutoRetainer** ウィジェットを足す

または [Releases](https://github.com/Qmeko/Umbra.AutoRetainer/releases/latest) から `Umbra.AutoRetainer.zip` をダウンロードして、中の DLL を Custom Plugins に追加します。

## 表示が出ないとき

- AutoRetainer が入っていないと、ウィジェット一覧に出ません
- 出ても `ARオフ` のときは、AutoRetainer を有効にして Umbra を再読み込みしてください
